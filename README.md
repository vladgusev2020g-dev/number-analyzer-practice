# Проверка характеристик числа

Практические работы №1 и №2.
Номер в списке — 7, вариант задания — 3.

## Назначение

Консольная программа анализирует целые числа, введённые пользователем.

## Возможности

- Определяет знак числа: положительное, отрицательное или ноль.
- Проверяет чётность.
- Проверяет делимость на 3 и на 5.
- Определяет, является ли число простым.
- Подсчитывает количество цифр без учёта знака.
- Определяет, является ли число квадратом целого числа.
- Позволяет анализировать несколько чисел за один запуск.
- Обрабатывает некорректный ввод числа и ответа о продолжении.

## Требования и запуск

Требуется Python 3.8 или новее.
Сторонние библиотеки не нужны.

Откройте терминал в папке проекта и выполните:

```bash
python3 main.py
```

## Использование

1. Введите целое число.
2. Прочитайте результаты анализа.
3. Введите «да», чтобы проверить следующее число.
4. Введите «нет», чтобы завершить программу.

При ошибочном вводе программа повторяет запрос.
Регистр букв и пробелы по краям ответа о продолжении не учитываются.

## Пример работы

```text
Введите целое число: 49

Ваше число: 49
Знак: положительное
Чётное: нет
Делится на 3: нет
Делится на 5: нет
Простое: нет
Количество цифр: 2
Полный квадрат: да

Проверить ещё одно число? (да/нет): нет
Работа программы завершена.
```

## Изменения в практической работе №2

Добавлен внешний цикл для анализа нескольких чисел подряд.
Добавлен вопрос о продолжении с проверкой ответа.
Добавлена проверка полного квадрата через math.isqrt:
квадрат целочисленного корня сравнивается с исходным числом.

Ноль является полным квадратом: 0 = 0 * 0.
Отрицательные числа не являются квадратами целых чисел.
