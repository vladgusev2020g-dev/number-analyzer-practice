# Практическая работа 1: проверка характеристик числа

Номер в списке: 7. При распределении четырёх вариантов по кругу выполняется вариант 3.

## Назначение

Консольная программа на Python анализирует введённое пользователем целое число.
Все вычисления находятся в одном файле main.py. Сторонние библиотеки не нужны.

## Решаемые задачи

- Определение знака: положительное, отрицательное или ноль.
- Проверка чётности.
- Проверка делимости на 3 и на 5.
- Проверка простоты.
- Подсчёт количества цифр без учёта знака.
- Обработка некорректного ввода с повторным запросом.

## Запуск

Требуется Python 3.6 или новее. Распакуйте архив и откройте терминал в папке practice_1.

Linux (Ubuntu, Debian):

```bash
python3 main.py
```

Windows:

```text
py main.py
```

## Использование

1. Запустите программу.
2. Введите целое число и нажмите Enter.
3. Прочитайте характеристики. После вывода программа завершится.
4. Для анализа другого числа запустите программу снова.

Допустимы отрицательные числа, ноль и положительные числа. Если ввести текст,
пустую строку или дробное число (например, 3.5), программа сообщит об ошибке
и предложит повторить ввод. Начальные нули не учитываются: 0013 анализируется как 13.

## Пример работы

```text
Введите целое число: abc
Ошибка: нужно ввести целое число, например 13, -6 или 0.
Введите целое число: 13

Ваше число: 13
Знак: положительное
Чётное: нет
Делится на 3: нет
Делится на 5: нет
Простое: да
Количество цифр: 2
```

## Особые случаи

Ноль чётный, делится на 3 и 5, не является простым и содержит одну цифру.
Единица и отрицательные числа не являются простыми. Двойка является простым числом.
Для -120 количество цифр равно 3: знак минуса не учитывается.

## Алгоритм проверки простоты

Сначала число считается простым, только если оно больше 1. Затем перебираются
возможные делители от 2, пока квадрат делителя не превосходит число.
Если найден делитель без остатка, число не простое и цикл прекращается.
Достаточно проверять до квадратного корня: в любой паре множителей составного
числа хотя бы один множитель не превышает его квадратный корень.
В худшем случае выполняется O(sqrt(n)) проверок делимости для положительного n.
Поэтому программа предназначена для учебных примеров, а не огромных простых чисел.

## Что использовано

input, int, print, f-строки, if/elif/else, while, break, try/except ValueError,
оператор остатка %, логическая переменная, abs, str, len, функция main.

В примере методички есть опечатка: вводится 30, но характеристики показаны для 13.
Программа анализирует именно введённое число.
